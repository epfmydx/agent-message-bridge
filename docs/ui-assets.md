# Local interface assets

The packaged wordmark, mark, favicon and CSS tokens are neutral assets authored for this project. They contain no external fonts, analytics, CDN code or imported organization artwork. SVG text uses the system monospace fallback; CSS and JavaScript are served locally.

The owner and participant interfaces share form and conversation components. Keep visible labels, keyboard focus, escaping, CSRF protection, responsive wrapping, readable contrast and stable history scrolling when changing presentation. Tests check the packaged files and template behavior; they do not establish every assistive-technology or real-device outcome.
